### 4. Feature Transformation Opportunities

- **Features**: `node_identifier`, `node_call`, `node_attribute`, `node_.`, `total_nodes`

- **Implementation**: `log(count + 1)` to handle zeros

#### Normalize by Code Length
- **Features**: `call_freq_*`, `uses_*`, `exception_type_*`
- **Benefit**: Make features scale-invariant; currently biased toward longer files
- **Implementation**: Divide by total lines of code or function count

#### Logit Transform for Bounded Features
- **Features**: All `*_ratio`, `*_density` features
- **Benefit**: Improve linearity for tree-based models
- **Implementation**: `logit(x) = log(x / (1-x))` with epsilon for boundary handling

#### Normalize Entropy Features
- **Features**: `identifier_entropy`, `call_vocabulary_size`
